# Миграция на общий edge-proxy

**Статус:** принято — дополняет [ADR-0001](0001-self-hosted-deployment.md).

**Контекст:** на сервере появился второй проект (ACM Hotels), которому тоже нужны порты 80/443 на том же хосте. Собственный контейнер `caddy` этого проекта раньше единолично держал эти порты через прямые биндинги `80:80`/`443:443`.

**Решение:** `caddy` и биндинги `80:80`/`443:443` убраны из `docker-compose.yml` этого проекта. Порты 80/443 теперь принадлежат независимому [edge-proxy](https://github.com/Fuberg/edge-proxy) — отдельному репозиторию/compose-проекту, который ни один из сайтов не владеет напрямую. Сервис `web` подключается к внешней Docker-сети `edge` под алиасом `tic-tac-toe-online`, по которому edge-proxy проксирует трафик.

**Почему:** держать TLS-терминацию в общем нейтральном прокси, а не в Caddy одного из проектов, — единственный способ не связывать доступность одного сайта с деплоями/рестартами другого на одном сервере.
